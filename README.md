# San Francisco Crime Analysis

## Overview

This project analyzes San Francisco crime incidents from 2003–2018 using Apache Spark and K-Means clustering.

## Technologies

- Databricks
- Apache Spark
- PySpark
- Spark SQL
- K-Means Clustering

## Analysis

- Crime Categories
- Crime by District
- Crime by Day of Week
- Crime by Year
- Crime by Hour
- Spatial Hotspot Analysis

## Dataset

San Francisco Police Department Incident Reports (2003–2018)
